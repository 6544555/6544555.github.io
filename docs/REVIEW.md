- **静态产物：通过。** `public/memories`、`dist/memories` 均为空；发布内容不含私密照片或文本。
- **Service Worker：通过。** SW v4 只在登录后的主站注册，不缓存 `content.json`、`/memories/`、REST 或 Storage 响应。
- **退出与失效清理：通过。** 主动退出清空主站、snapshot、认证缓存、token 和签名 URL 内存缓存；自动 `SIGNED_OUT` 与 401/403 复核也有测试。
- **Git 隔离：通过。** 本地 `main` 根提交存在；`.env` 历史 0 条、索引未命中。
