# UI 精修与背景音乐布局记录

日期：2026-11-14  
范围：黑白编辑档案册视觉精修；认证、RLS、数据层和页面流程未改变。

## 视觉调整

- 登录页：近黑场域、纸白信纸边缘、深灰偏移阴影、封签与短轴线强化入口层级。
- 主站首屏：标题增加平衡换行，站点名称、日期印章和操作区形成同一编辑轴线。
- 区块标题：编号使用黑色粗边索引，标题下沿保持粗墨线。
- 照片墙：contact-sheet 网格加入非均匀节奏，每 7 张设置一张跨两列主照片并使用 `3:2` 画幅，其余保持 `4:5`。
- 照片装饰：照片区标题与网格之间增加两枚黑白线稿气球和两枚小面积粉色爱心；装饰带 `aria-hidden`，不拦截操作，与标题保持 20–34px 间距。
- 交互：悬停与键盘焦点只加深边框、说明底和分隔线，不发生位移。
- 时光轴：日期列增加细线，内容列形成纵向档案栏；移动端改为黑色竖线引导。
- 留言区：移除包裹式卡片，改为顶部粗线、底部细线的档案批注布局。
- 空状态与页脚：增加索引条和短墨线锚点，保持黑白灰层级。
- 动效仅使用既有 120/180/260ms token；减少动效模式不移动元素。

## 手机端删除修正

- 大图层通过 React Portal 挂载到 `document.body`，避免被页面区块的 transform 影响固定定位。
- 弹层改为固定高度三行网格：标题、可滚动图片区、固定操作栏。
- 375×812 实测弹层位于 `41–771px`，操作栏 `677–739px`，删除按钮 `693–739px`，无需向下滚动即可操作。

## 背景音乐布局

- 音乐按钮位于 `masthead-actions`，与退出登录按钮同组，不占用主导航。
- 默认音频：`public/audio/memory-theme.ogg`，`58006` 字节，文件头 `OggS`。
- 按钮显示的公开尺寸：`92×44px`。
- 按钮使用 `aria-pressed` 表达播放状态；无自动播放。

## 响应式证据

| 视口 | 照片列数 | 主照片/普通照片宽 | 装饰与标题间距 | 横向溢出 | 小于 44px 控件 | 音乐按钮 |
|---|---:|---:|---:|---|---:|---|
| 375×812 | 2 | 341 / 159px | 34px | 否 | 0 | 92×44px |
| 768×1024 | 3 | 457 / 213px | 20px | 否 | 0 | 92×44px |
| 1440×900 | 4 | 583 / 276px | 20px | 否 | 0 | 92×44px |

移动端音乐操作区宽 `343px`，导航宽 `343px`，没有被音乐按钮挤压。音乐按钮实测可进入 `aria-pressed=true` 播放状态。
