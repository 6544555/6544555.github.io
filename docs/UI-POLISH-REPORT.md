# UI 精修与背景音乐记录

日期：2026-11-14  
当前方向：v6 暖米纸编辑部动态体验
范围：只调整视觉层；Auth、RLS、数据、导出、六状态和页面流程保持不变。

## 1. 视觉系统

- 画布：`paper #F9F8F6`；主文字与线框：`ink #1C1C1C`；辅助文字：`graphite #6B7280`。
- 唯一彩色：`mauve #816D70`，只用于小爱心、选中态和极小面积强调。
- 标题使用 Georgia / Songti 系统衬线；正文、按钮、导航使用 Inter / 系统无衬线。
- 桌面显示标题 72px，区域标题 48px；正文 16px；标签 12px。
- 所有按钮、输入、照片和弹层圆角为 0；普通元素无阴影、无渐变。
- 区块间距 96px；移动端页面边距 24px，桌面 48px。
- 桌面首屏为约 45/55 的编辑分栏；区块标题使用前置短线与发丝分隔线。

## 2. 照片与装饰

- 照片墙在 375/768/1440 分别保持 2/3/4 个轨道。
- 普通照片保持 `4:5`；每 7 张首张横跨两列并使用 `3:2`。
- 照片列表使用顶部发丝线与慢速图片缩放，不使用卡片阴影。
- 照片标题与网格之间保留独立装饰带：两枚黑白线稿气球、两枚陈玫色爱心。
- 装饰带 `aria-hidden`、`pointer-events: none`，不遮挡标题和操作。

## 3. 音乐

- 默认音频：`public/audio/memory-theme.wav`，1,469,070 bytes，WAV PCM，33.31 秒。
- 音乐播放与“换音乐”按钮位于 `masthead-actions`，均保持 44px 以上；播放时显示三条均衡器短线。
- 登录后可从本机上传 16MB 内的 MP3、WAV 或 M4A 到 Supabase 私有 `music` 桶。
- 真实回归：上传 MP3 后音频源切换到 Supabase 私有签名地址，刷新后仍读取自选音轨，恢复默认后重新使用打包音轨并清理自选文件。
- 不强制首次自动播放；减少动效时关闭均衡器动画。

## 6. v6 动态强化

- 首屏重构为完整杂志封面：题句、导语、翻开照片动作、天数、音频和爱心雨集中在首屏，下一区块在 375/768/1440 均保留可见提示。
- 新增“小黑爱心雨”：单次落下 34 枚纯黑小爱心，动画层通过 Portal 挂到 `body`，`pointer-events: none` 且 `aria-hidden`，不会被页头裁切或阻挡操作。
- 主区块使用 `IntersectionObserver` 首次进入视口时显现；粘性导航使用编号和发丝下划线标示操作，没有监听滚动事件。
- 新增跳到主要内容链接；空状态改为不对称编辑构图，照片增加 PLATE 编号、题注衬线和慢速图片缩放。
- `prefers-reduced-motion: reduce` 下关闭移动与下落，直接显示区块，并将爱心雨替换为静态爱心排列。
