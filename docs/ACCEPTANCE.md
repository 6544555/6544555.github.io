# 验收清单 A1–A28

版本：v4.0  
判定原则：每一项只接受可观察证据；代码里存在不代表运行时通过。无法执行的项写明“未验证”，不得估算为通过。  
权限模型：Supabase Auth 关闭公开注册，只保留一个共享邮箱密码账号；匿名访客只能看到公开登录入口。
`[P0]` 共 8 项：A1、A2、A4、A7、A21、A23、A26、A27。任一 P0 不通过即不可交付。

## A. 基础与登录

- [ ] **A1 [P0] 匿名隔离**：清空浏览器存储后打开站点，只出现公开壳层与登录表单；页面没有注册入口，Elements 中找不到私密照片文件名、时光正文或留言正文，Network 中没有三表 REST、Storage 或照片请求。
- [ ] **A2 [P0] 共享账号登录**：输入唯一共享邮箱与密码后，2 秒内进入主站；刷新后有效会话保持；退出后立即回到登录页。
- [ ] **A3 错误密码**：输入错误密码显示统一提示，不透露邮箱是否存在；页面不进入主站，也不发起业务表请求。
- [ ] **A4 [P0] 公开壳层优先**：认证检查延迟 8 秒时，登录信和公开壳层在 1.5 秒内可见且不白屏；未认证期间私密请求为 0。
- [ ] **A5 基础浏览**：主站在 375×812、768×1024、1440×900 三个视口可浏览；375px 下 `document.documentElement.scrollWidth` 等于视口宽度。

## B. 照片与内容

- [ ] **A6 批量上传**：一次选择 3 张有效 JPEG/PNG/WebP，逐张出现进度，成功后显示同数量新照片；任意一张失败不回滚其余成功项。
- [ ] **A7 [P0] 共享账号跨设备**：设备 A 用共享账号上传 1 张照片；设备 B 不使用同一浏览器存储，用同一共享账号登录后能看到同一照片并打开大图。
- [ ] **A8 删除二次确认**：点击删除后出现包含对象标题或日期的确认层；按 Escape 或“留下”不发起删除请求，确认后刷新仍不显示该对象。
- [ ] **A9 时光轴增删改**：新建标题 30 字、正文 500 字的条目可保存；编辑后刷新内容更新；按日期倒序显示，同日期按创建时间倒序。
- [ ] **A10 留言纯文本**：提交包含换行与 `<script>alert(1)</script>` 的留言，换行保留、脚本作为文字显示且不执行；刷新后仍可见。
- [ ] **A11 彩蛋计数**：起始日当天显示“第 0 天”；次日起逐日加 1；跨月、跨年结果与真实自然日差一致。
- [ ] **A12 三处空状态**：清空对应数据后分别出现照片、时光、留言空状态；区域高度与有内容时预留最小高度一致，无加载提示与空状态叠加。
- [ ] **A13 导出闭环**：登录用户点击“带走一份备份”后生成 `memories-YYYY-MM-DD.zip`，包内至少有 `content.json`、照片目录和说明文件；导出中按钮不可重复触发。
- [ ] **A14 本地字体**：断开局域网后刷新，标题与正文仍使用已部署字体或明确回退字体；Network 中无 Google Fonts 或第三方字体请求。
- [ ] **A15 减少动态效果**：开启 `prefers-reduced-motion: reduce` 后，拆信、照片悬停抬升、列表落位均不移动或缩放；页面直接可操作。
- [ ] **A16 键盘与焦点**：不使用鼠标可完成登录、打开大图、关闭大图、提交留言；大图关闭后焦点回到原照片，焦点轮廓始终可见。
- [ ] **A17 触控尺寸**：375px 视口中所有按钮、链接和图表控制项的可点击区域至少 44×44px；相邻操作不重叠。
- [ ] **A18 设计 token**：界面颜色只使用 DESIGN 中 6 个 hex 及其透明叠加；字号、间距、圆角、动效时长可在样式中对应到登记 token，无自创关键值。
- [ ] **A19 可读性**：正文与底色对比度至少 4.5:1；每张内容照片有非空替代文本；按钮有可访问名称。
- [ ] **A20 范围与索引**：页面没有 SPEC 之外的可操作入口；源码含 `noindex, nofollow`，发布后的 `robots.txt` 对全部路径拒绝抓取。

## C. 云端与会话

- [ ] **A21 [P0] 登录后断网降级**：成功登录并加载主站后切为离线再刷新，已认证壳层和本地文本快照可读，页面不白屏；写操作禁用，状态句来自 `cloud.offline`。
- [ ] **A22 暂停状态**：将读取请求模拟为项目暂停特征，显示 `cloud.paused`，不出现“错误/失败/异常/无权限/服务器/500”，界面无重试按钮。
- [ ] **A23 [P0] 退出清理**：点击退出后主站、私密 DOM、文本快照、认证用户标记和签名 URL 内存缓存全部清除；刷新后只显示登录入口，浏览器后退不恢复私密内容。
- [ ] **A24 保活真实接口**：GitHub Actions 的 keepalive 手动运行成功；日志显示共享账号登录和对数据表的实际读取均为 HTTP 2xx，access token 被 mask；人为令账号或密钥无效时工作流退出非零并标红。
- [ ] **A25 超大文件边界**：选择 8.1MB 与 10MB 图片，两者都在本地被拒绝且 Network 中无该文件上传请求；页面保持可操作，其他小图仍可上传。
- [ ] **A26 [P0] 管理密钥隔离**：扫描源码、环境示例和构建产物中的真实管理密钥赋值/JWT 值，不得存在 `service_role` 类密钥；安全文档中说明“不得使用管理密钥”的警示文字不计为命中。
- [ ] **A27 [P0] 环境文件隔离**：`.gitignore` 包含 `.env`；`git log --all -- .env` 无输出；`git ls-files --error-unmatch .env` 返回非零；`.env.example` 所有键值均为空。
- [ ] **A28 备份可恢复**：把 A13 的 zip 解压到全新目录，在登录后的新会话中导入或替换内容后，所有文字与照片数量一致，无缺图或乱码。

## D. 视觉与音乐增量

- [ ] **A29 非均匀照片编排**：有至少 7 张照片时，每 7 张中的首张横跨两列并保持 3:2，其余照片仍为 4:5；375/768/1440 分别保持 2/3/4 个轨道且无横向溢出。
- [ ] **A30 庆祝点缀不干扰**：照片区显示两枚黑白线稿气球和两枚粉色爱心；装饰 `aria-hidden`、不拦截点击、不覆盖标题或按钮，粉色只用于爱心。
- [ ] **A31 自定义背景音乐**：登录后点击背景音乐按钮可播放/暂停循环音轨；刷新后播放偏好保留；默认 OGG 响应为 `audio/ogg`，自定义 URL 可替换；按钮至少 44px 且不影响导航布局。

## E. 证据记录格式

验收报告逐项使用以下列，不得只写“通过”：

| 编号 | 结果 | 环境 | 操作 | 证据 |
|---|---|---|---|---|
| A21 | 通过 / 未通过 / 未验证 | 浏览器与版本、视口 | 可复现步骤 | 截图路径、日志摘要或实际观察 |

证据规则：

- 云端暂停、额度满、跨设备、保活、备份恢复必须保留实际日志或截图。
- 匿名隔离、退出清理和认证错误必须分别保留独立浏览器 profile 的网络记录。
- 断网无法模拟时写“未验证”和未执行原因，不得写“通过”。
- 任何 P0 为“未验证”时，交付状态不得标为 `DONE`。
- 页面可见文案检查必须从实际 DOM 或截图读取，不以源码推断。
