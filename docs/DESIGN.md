# 私人纪念空间设计规范

版本：v4.0 · 带庆祝点缀的黑白编辑档案册  
方向：以黑白摄影集为主体，用小面积粉色爱心、纸片气球和有节奏的照片编排增加温度；不使用彩色主题、营销卡片或装饰性光效。  
视觉关键词：秩序、留白、纸张、墨线、时间感、轻柔庆祝。

## 1. 颜色

| token | hex | 用途 |
|---|---|---|
| paper | `#F6F6F6` | 页面底色、输入底、照片说明纸面 |
| wash | `#E8E8E8` | 骨架屏、空状态、次级表面 |
| ink | `#111111` | 标题、正文、主按钮、主要边界 |
| graphite | `#383838` | 实心次级块、查看层背景、数字标记 |
| muted | `#666666` | 日期、辅助说明、禁用文字 |
| line | `#BDBDBD` | 分隔线、次级边框、非活动标记 |
| heart | `#D78A9F` | 仅限小面积爱心装饰 |

规则：主体只使用黑、白、灰；粉色只用于不可交互的爱心点缀，不用于文字、按钮、边框或状态。照片本身保留原色；不得新增其他品牌彩色、渐变或彩色阴影。

## 2. 字号阶梯

| 级别 | 移动端字号/行高 | 桌面端字号/行高 | 字重 | 用途 |
|---|---|---|---|---|
| display | 44px / 48px | 72px / 76px | 500 | 登录页标题、首屏唯一主句 |
| h1 | 34px / 40px | 48px / 54px | 500 | 区域标题 |
| h2 | 22px / 30px | 26px / 34px | 600 | 照片说明标题、时光轴条目标题 |
| lead | 18px / 30px | 20px / 32px | 400 | 引导句、空状态正文 |
| body | 16px / 28px | 16px / 28px | 400 | 正文、输入内容 |
| caption | 12px / 18px | 12px / 18px | 500 | 日期、索引、辅助说明、按钮小字 |

字距统一为 0。标题系统使用 `"Songti SC", SimSun, Georgia, serif`；正文使用 `"Helvetica Neue", Arial, "Microsoft YaHei", "PingFang SC", sans-serif`。不请求外部字体。

## 3. 间距体系

| token | 值 | 典型用途 |
|---|---:|---|
| space-1 | 8px | 图标与文本、日期与标题 |
| space-2 | 16px | 段落、字段内部、按钮组 |
| space-3 | 24px | 移动端页面边距 |
| space-4 | 32px | 卡片内容、区域内部节奏 |
| space-5 | 40px | 移动端区域间距 |
| space-6 | 48px | 桌面端组件间距 |
| space-7 | 64px | 区域留白 |
| space-8 | 88px | 首屏与登录页留白 |

页面最大内容宽度 1200px；桌面左右安全边距至少 48px，移动端至少 16px。正文行宽控制在 28em 内。

## 4. 圆角、边框、阴影

| 项目 | 值 | 用途 |
|---|---|---|
| radius-square | 0 | 按钮、输入、照片、查看层 |
| border-hair | 1px solid `#111111` | 主边界、照片外框、选中态 |
| border-soft | 1px solid `#BDBDBD` | 分区、次级边界 |
| rule-strong | 2px solid `#111111` | 区域标题下沿、当前日期标记 |
| shadow-none | none | 普通卡片与照片默认无阴影 |
| shadow-viewer | `0 24px 80px rgba(0,0,0,0.26)` | 仅照片查看层和确认弹层 |

主按钮为实心黑底白字，次按钮为透明白底黑字；禁止胶囊按钮、玻璃拟态、彩色渐变与装饰光晕。

## 5. 动效

| token | 时长 | 曲线 | 用途 |
|---|---:|---|---|
| motion-fast | 120ms | `cubic-bezier(0.2, 0, 0, 1)` | 按钮、焦点、链接 |
| motion-base | 180ms | `cubic-bezier(0.2, 0, 0, 1)` | 首屏揭幕、查看层进入 |
| motion-slow | 260ms | `cubic-bezier(0.2, 0, 0, 1)` | 新增内容落位、照片反馈 |

照片不做持续漂浮或随机旋转。`prefers-reduced-motion: reduce` 下不位移、不缩放、不旋转，只允许 80ms 淡入。

## 6. 字体与加载

- 不请求在线字体，使用系统宋体标题与系统中性无衬线正文。
- 不下载字体文件，避免首屏阻塞与授权文件遗漏。
- 字体回退必须包含 Windows 与 macOS 常见中文字体。
- 字号固定，不随视口宽度连续缩放；只在 768px 断点切换一次桌面级别。

## 7. 布局与响应式

- 375px 到 767px：照片墙 2 列，页面边距 16px；时光轴和留言改为单列。
- 768px 到 1199px：内容最大 920px，照片墙 3 列。
- 1200px 及以上：内容最大 1200px，照片墙 4 列。
- 照片格默认 4:5；每 7 张允许一张 3:2 重点照片横跨两列，并允许一张向下错位，保持可扫描顺序。
- 使用细黑边框、无旋转、无厚白边；节奏变化不得产生空洞或横向溢出。
- 照片区标题附近可放 2 个黑白纸片气球和 2 个粉色线稿爱心，装饰不得覆盖内容。
- 所有控件至少 44×44px；键盘焦点使用至少 2px 的高对比焦点环：浅底为墨黑，深底反转为纸白。
- 375px 下不得出现横向滚动；连续字符可断行。

## 8. 骨架屏

- 基色 `wash`，高光 `paper`；仅使用黑白灰 token。
- 矩形无圆角；脉冲从透明度 0.55 到 1.0，周期 1200ms。
- 照片骨架保持 4:5 比例；文字骨架高 18px、14px，行距 8px。
- 骨架和真实内容共用轨道与最小高度，切换时不改变布局。

## 9. 关键界面

### 9.1 登录页

整屏近黑背景，一张无圆角的白色信纸居中，左上角只保留小型双线封签。标题用 44px 宋体，共享邮箱与密码是两条黑色书写线；提交按钮为整块黑底白字。页面不显示注册、邀请或账号名单入口，提示信息在按钮上方的固定区域出现。

为什么：黑色场域让入口像一本合上的摄影集，白纸与书写线负责邀请，不使用彩色强调也能建立仪式；单一共享入口保持操作简单，但身份验证仍由 Supabase Auth 承担。

### 9.2 首屏

黑色幕布分成上下两片，180ms 内让出静态照片墙；跳过按钮固定在右上，样式为白底黑框。主标题使用大号宋体，日期印章改为黑色矩形标签。动效不延迟内容挂载，也不阻止滚动。

为什么：揭幕只制造一次空间转换，照片而非动画成为第一视觉焦点。

### 9.3 照片墙

照片如 contact sheet 对齐：1px 黑框、0 圆角、无外阴影，日期用 12px 大写字距为 0 的序号文字放在图下。悬停把边框加粗到 2px，并在 120ms 内轻微加深说明；不使用随机旋转、抬升或彩影。每 7 张照片形成一次大图与错位节奏，避免所有格子完全一致。

标题与照片之间保留一条低高度的纸片装饰带：两个黑白线稿气球、两个小粉色爱心，像纪念册页边的手工标记，不遮挡照片。用户点击播放后出现低响度循环背景音乐；按钮保持 44px，并在播放时显示三条均衡器短线。

为什么：有序网格把注意力交给照片内容，适度的大小节奏和庆祝符号让空间更像被珍藏的生日档案，而不是普通图库。

### 9.4 降级态

降级位是一条固定的浅灰索引条：左侧 2px 黑线，右侧一句状态文字；96px 高度保持不变，静态照片不移动，看起来像档案册里的检索备注。

## 10. 内容语气

- 句子短，陈述状态，不使用客服口吻、网络流行语或连续感叹号。
- 云端状态不指责用户，不出现技术词，不伪造“马上就好”。
- 所有真实姓名、日期、故事与照片由内容文件替换。
- 黑白不是冷酷：温度来自照片、留白、真实文字和稳定节奏。

## 11. 无障碍与交互

- 所有内容图片必须有替代文本；纯装饰元素不进入可访问树。
- 图标按钮必须有可读名称和可见焦点；不得只用颜色表达状态。
- 输入标签常驻可见；焦点轮廓在黑白背景上保持清晰。
- 查看层锁定背景滚动、限制焦点循环，关闭后把焦点还给触发项。
- 正文与底色对比度至少 4.5:1；大字号至少 3:1。

## 12. 明确不做

- 不做大面积彩色强调：粉色只限爱心装饰，不改变黑白主体。
- 不做渐变、玻璃、发光或装饰球；气球只使用纸片线稿。
- 不做随机旋转和厚相框：照片节奏必须稳定、可扫描、可回退。
- 不做深色模式：首版只维护一套纸面系统。
- 不做多语言、点赞、分享、关注：保持私人纪念空间边界。
- 不做强制自动播放：背景音乐必须由用户第一次点击开启。
- 不做无限滚动：内容应能被完整浏览与定位。
