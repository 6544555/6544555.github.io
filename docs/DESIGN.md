# 私人纪念空间设计规范

版本：v5.0 · 暖米纸编辑部
方向：高端杂志与报纸的版面语言。表现力来自衬线标题、字号级差、留白、发丝线与照片，不来自卡片、阴影、圆角或渐变。
视觉关键词：印刷感、秩序、呼吸、私密、克制庆祝。

## 1. 颜色

| token | hex | 用途 |
|---|---|---|
| ink | `#1C1C1C` | 正文、标题、1px 边框、反色区块 |
| paper | `#F9F8F6` | 页面画布、输入底、弹层底 |
| graphite | `#6B7280` | 次级文字、日期、题注、辅助说明 |
| mauve | `#816D70` | 唯一彩色点缀；仅爱心、选中态和极小面积强调 |
| wash | `#F0EEE9` | 骨架屏、空状态、轻量背景层 |
| rule | `#D8D4CE` | 发丝分隔线与普通边界 |
| white | `#FFFFFF` | 需要最高明度对比的纸面细节 |

规则：不使用其他彩色，不使用纯黑 `#0A0A0A` 或冷白 `#FAFAFA` 作为主色。彩色面积不超过一屏 2%。照片保留原色；线框优先使用 ink 的透明叠加。

## 2. 字体

- 标题、数字、引文：`Georgia, "Times New Roman", "Songti SC", SimSun, serif`。
- 正文、按钮、标签、导航：`Inter, "Helvetica Neue", Arial, "Microsoft YaHei", "PingFang SC", sans-serif`。
- 不请求外部字体；使用系统中可用回退。

| 级别 | 移动端字号/行高 | 桌面端字号/行高 | 字重 | 用途 |
|---|---|---|---|---|
| display | 44px / 48px | 72px / 76px | 400 | 首屏主句、登录标题 |
| heading-lg | 36px / 40px | 48px / 54px | 400 | 区域标题 |
| heading | 28px / 36px | 36px / 44px | 400 | 条目标题 |
| subheading | 22px / 30px | 28px / 36px | 400 | 次级标题、空状态 |
| body-lg | 16px / 28px | 16px / 28px | 400 | 导语、长正文 |
| body | 14px / 24px | 14px / 24px | 400 | 题注、说明 |
| label | 12px / 18px | 12px / 18px | 500 | 日期、索引、按钮、导航 |

字距统一为 0。标签以字号、字重和结构线区分，不使用负字距。

## 3. 间距

| token | 值 | 用途 |
|---|---:|---|
| space-1 | 8px | 元素内部 |
| space-2 | 16px | 行间距、按钮组 |
| space-3 | 24px | 移动端容器内边距 |
| space-4 | 32px | 段落与表单节奏 |
| space-5 | 48px | 桌面容器内边距、栏间距 |
| space-6 | 64px | 条目间距 |
| space-7 | 96px | 区块间距 |
| space-8 | 128px | 首屏与大型留白 |

页面最大宽度 1200px；移动端页面边距 24px，桌面 48px。阅读正文宽度不超过 34em。

## 4. 边界、圆角与深度

| 项目 | 值 | 用途 |
|---|---|---|
| radius-all | 0 | 所有卡片、按钮、输入、图片、弹层 |
| rule-hair | `1px solid rgba(28,28,28,0.10)` | 列表、卡片顶部、次级分区 |
| rule-hover | `1px solid rgba(28,28,28,0.40)` | hover 时的边界加深 |
| rule-ink | `1px solid #1C1C1C` | 主按钮、选中态、输入焦点 |
| shadow | none | 普通内容、照片、按钮、弹层 |

普通界面不使用阴影。弹层依赖反色遮罩、直角边框和留白建立层级。

## 5. 动效

| token | 时长 | 用途 |
|---|---:|---|
| motion-fast | 200ms | 按钮、链接、边框 |
| motion-base | 360ms | 弹层与首屏 |
| motion-slow | 500ms | 下划线展开、照片慢速放大 |

缓动统一使用 `cubic-bezier(0.16, 1, 0.3, 1)`。`prefers-reduced-motion: reduce` 下取消位移、缩放、下划线动画与连续均衡器动画，只允许 80ms 淡入。

## 6. 布局

- 375px 到 767px：单栏内容，照片墙 2 列，页面边距 24px。
- 768px 到 1199px：照片墙 3 列，内容最大 920px。
- 1200px 及以上：照片墙 4 列，内容最大 1200px。
- 区块间距 96px；容器内边距 24px 到 48px；正文单栏或两栏。
- 桌面首屏使用约 45/55 的编辑分栏：左侧标题与导语，右侧日期、音乐、退出和版次信息。
- 不出现三栏以上的密集正文，不堆叠卡片，不产生横向滚动。

## 7. 组件

### 主按钮

墨黑实底、纸色文字、直角、1px ink 描边；标签 12px、500 字重；padding 16px 32px。hover 时纸色底、墨黑字；focus-visible 使用 2px ink 外框。

### 次级文本链接

无背景无外框，12px 标签级；下方 1px 当前色线，hover 从右向左展开，200–500ms；focus-visible 使用高对比轮廓。

### 发丝列表项

顶部 1px rgba ink/10 边线，padding-top 24px，无背景、无阴影、无圆角。hover 时边界加深到 /40，照片最多放大到 `1.02`。

### 区块标签

12px、无衬线、graphite；前置 24px 长、1px 宽墨线，线与文字间距 12px。不增加装饰框。

### 引文与空状态

衬线 28–36px，左右缩进 24px，左侧 2px ink 竖线，上下留白 32px。引号可使用 mauve，仅在极小面积出现。

## 8. 照片墙与庆祝装饰

- 每 7 张首张作为独立整行 3:2 主图；其余照片按高度权重分配到 2/3/4 个均衡列桶，并循环使用 4:5 普通图、1:1 方幅、3:4 竖幅和向下错位节奏。
- 照片循环应用黑色细框、白卡纸、双线框、深墨框和灰纸内衬五类相框；所有相框只用边线、纸色与留白，无圆角无阴影。
- 相片库使用同一照片数据生成 contact sheet，375/768/1440 为 2/3/4 列；点击缩略图进入原大图查看、删除和二次确认流程。
- 选择照片后立即显示真实缩略图与处理状态；上传成功后原位出现正文照片、`新入册` 标记和一次短促入场，当前批次无需等待文件列表刷新。
- 照片格无圆角无阴影；图片在 hover 时最多放大 1.025，容器保持固定比例。
- 两枚黑白线稿气球与两枚小面积 mauve 爱心放在标题和照片之间的独立装饰带，不覆盖内容、不接指针、不进入无障碍树。
- 粉色 `#D78A9F` 退出设计系统；爱心改用 mauve `#816D70`。

## 9. 登录页

暖米纸画布，中心是一张直角纸页；左侧或上沿用窄墨黑带建立封面感。标题为 44–72px 衬线，空白账号框与密码沿发丝线输入。页面不出现账号提示、内部邮箱、注册、邀请、账号列表或密码提示。按钮为墨黑实底直角按钮，错误提示占用固定高度，不得推动布局跳动。

## 10. 主站首屏

左侧为实时相识计时器、称呼与日期；计时器显示“相识至今 N 天 HH:MM:SS”，数字使用衬线体和等宽数字特性，每秒更新但不触发读屏连续播报。右侧为版次标记、音乐和退出操作。页面以 96px 以上留白与发丝线分区，没有营销卡片。减少动效时直接显示全部内容。

## 11. 页面动效与爱心雨

- 首屏题句、导语与操作按 760ms 的减速曲线依次进入；主区块使用 `IntersectionObserver` 首次显现，不使用未节流的滚动监听。
- 导航保持粘性，以编号、背景切换和 1px 下划线表达位置；照片只做 1.025 倍以内慢速缩放。
- 页头提供可开启和关闭的爱心彩蛋开关。开启后全屏持续落下 70 枚彩蛋，由 5 种颜色的小爱心、红玫瑰和玫瑰花苞共 7 类组成；动画层挂载到 `body`，不进入可访问树且不拦截页面操作。
- 编辑点缀只使用极小面积：导语与页脚各一枚空心爱心，桌面页边使用竖排 folio 标签与单枚分区符号，移动端隐藏页边标记。
- 气球与爱心装饰带使用 5.8 秒慢速漂浮；所有移动仅使用 `transform`、`translate` 与 `opacity`。
- 留言区后、页脚前使用一条黑色动态心电图作为下半页呼吸点：底层细线常驻，墨色脉段沿 SVG 路径循环；375px 高度 64px，桌面最高 96px。
- `prefers-reduced-motion: reduce` 下取消位移、下落和心电扫描，内容直接显示，爱心类彩蛋与完整心电波形改为静态排列。

## 12. 背景音乐

音乐播放与“换音乐”按钮放在页头操作区，均保持至少 44px；播放时以三条短线表达状态，设置按钮使用文字底线，不增加新的图标依赖。音乐设置使用无圆角弹层，提供当前音轨状态、选择文件和恢复默认三项操作。用户首次点击前不播放；刷新后保留用户已开启的偏好。上传或资源错误只在设置层显示可重试提示，不影响其他功能。

## 13. 无障碍

- 内容图片必须有替代文本；纯装饰不进入可访问树。
- 键盘焦点始终可见；浅底用 ink，深底用 paper。
- 输入标签常驻；弹层锁定背景滚动、限制焦点循环、关闭后还焦。
- 登录表单使用 `noValidate` 与页面内编辑式校验注记，不触发浏览器原生校验气泡；账号输入使用用户名自动填充，内部邮箱只在构建时映射。
- 登录输入框不使用整圈焦点矩形，聚焦时以墨色底线、内嵌 1px 线和浅纸底色表达键盘焦点。
- 正文与底色对比度至少 4.5:1；大字号至少 3:1。
- 可点击区域至少 44×44px。

## 14. 明确不做

- 不做渐变、背景图案、装饰几何和光晕。
- 不做卡片阴影、玻璃拟态和圆角。
- 不做大面积彩色或第二种强调色。
- 不做冷白与纯黑主导的冷硬后台风格。
- 不做无限滚动、自动轮播、社交互动或公共注册。
- 不做强制自动播放；音乐必须由用户首次主动开启。
